功能
輸入關鍵字及權重
自動抓取網頁內容
計算關鍵字出現次數
根據關鍵字權重計算分數
自動擷取網頁中的超連結
建立網站樹狀結構
將子頁面的分數納入評分

系統架構
WebTree
│
└── Root Page
    ├── Child Page 1
    └── Child Page 2


類別：
WordCounter:
抓取網頁內容
移除 HTML 標籤
統計關鍵字出現次數
擷取超連結

WebPage:

代表單一網頁。

計算網頁內各關鍵字出現次數
根據關鍵字權重計算頁面分數

分數計算方式：

關鍵字次數 × 權重

再依照網頁總字數進行正規化，避免文章越長分數越高。

WebNode:
代表網站樹中的一個節點。

除了記錄自己的分數外，也會參考子頁面的分數：
Node Score = 自身分數 + 0.6 × 子頁面分數

WebTree:
負責建立整個網站樹。

功能：
自動建立子節點
避免重複拜訪相同網址
遞迴計算所有節點分數

目前設定只往下探索一層子頁面。

評分流程
輸入關鍵字
      ↓
抓取網頁內容
      ↓
統計關鍵字次數
      ↓
計算頁面分數
      ↓
建立網站樹
      ↓
加入子頁面影響
      ↓
得到最終分數

使用技術:
Java
Java HttpClient
Regex
Tree Data Structure
Recursive Traversal
